# Codigo de conducta

## Nuestro compromiso

Queremos una comunidad abierta, respetuosa y libre de acoso para todo el mundo,
sin importar edad, diversidad funcional, etnia, identidad o expresion de genero,
nivel de experiencia, nacionalidad, apariencia, religion o identidad sexual.

## Comportamientos esperados

- Trato amable y critica constructiva sobre el codigo, no sobre las personas.
- Respeto a la privacidad: nada de compartir documentos, claves o datos de otros.
- Aceptar la correccion y pedir perdon cuando se falla.
- Priorizar lo que beneficia al proyecto y a quien estudia con el.

## Comportamientos inaceptables

- Acoso, insultos, comentarios discriminatorios o ataques personales.
- Publicar informacion privada de otras personas sin permiso.
- Publicar claves de API o documentos ajenos.
- Usar el proyecto para facilitar trampas academicas.

## Aplicacion

Los maintainers pueden eliminar comentarios, cerrar issues o expulsar a quien
incumpla estas normas. Para reportar un problema de conducta, contacta de forma
privada con los maintainers del repositorio.

Este codigo se basa en el
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
